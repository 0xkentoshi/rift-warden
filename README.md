# RIFT // WARDEN

Небольшая законченная лаборатория для тестового задания MOX «AI-first Developer 2.0 — Лаборатория нестабильных порталов».

[Приложение](https://0xkentoshi.github.io/rift-warden/) · [GitHub](https://github.com/0xkentoshi/rift-warden) · [CI / публикация](https://github.com/0xkentoshi/rift-warden/actions)

Исследуйте шесть разломов, управляйте риском и удерживайте сеть. Характеристики любого портала можно посмотреть кликом из любой точки комнаты. Действия доступны только рядом: подойдите персонажем и нажмите E или используйте уже открытую карточку в радиусе взаимодействия. Все исходные поля, ограничения, предупреждение о существах, журнал, отчёт и отдельный AI Worklog сохранены.

## Запуск

Node.js 24 LTS, npm. Секреты, ключи и сервер не нужны.

```sh
npm ci
npm run dev
```

Откройте адрес Vite (обычно http://localhost:5173).

```sh
npm test
npm run lint
npm run build
npm run preview
```

Production-файлы — `dist/`; preview обычно http://localhost:4173. CI выполняет тесты, lint и сборку после чистого `npm ci` перед GitHub Pages.

## Quick Review Path — 1–2 минуты

1. Прочитайте **How to Play → Start Shift**.
2. Откройте **Реестр порталов**: все шесть порталов и обязательные поля ТЗ. Реестр — только мониторинг.
3. Кликните **Crimson Gate** из любой точки: удалённо посмотрите характеристики и **Risk breakdown**. Действия пока недоступны.
4. Подойдите к **Crimson Gate** персонажем. Нажмите **E** или оставьте карточку открытой: в радиусе взаимодействия действия включатся.
5. **Send Observer**: получите объяснённый CRITICAL rejection и запись в истории.
6. **Stabilize → Confirm**: проверьте изменение параметров и снижение Risk.
7. Подойдите к **Azure Bloom**: Intel 100%, существ нет — проверьте **Safe Close**.
8. Рядом с порталом с существами / неполным Intel проверьте **Force Close warning**. **Cancel** ничего не меняет.
9. **Event Log**: действия, отказы, системные события и изменения параметров.
10. **System Report**: счётчики, приоритеты и сводка сети.
11. **AI Worklog**: инструменты, время, роли автора/AI, ключевые запросы и решения.
12. **System → Load empty-lab scenario**. Возврат: **Settings → Restart Shift → подтверждение**.

Полное прохождение не требуется: обязательные требования ТЗ можно проверить примерно за 1–2 минуты. **Time Scale 0.5× / 1× / 1.5× / 2× / 5×** меняет скорость симуляции, countdown, Stability drift, игровых таймеров и персонажа; отзывчивость UI не меняется.

## Игровой цикл и баланс

Сложность растёт по часовой стрелке: **green 1 → orange 2 → blue 3 → black 4 → purple 5 → red 6**. Порядок свободный. Уровень влияет на цену экспедиций, отдачу Intel, вклад в сеть и последствия ударов; он не прибавляется напрямую к внутреннему риску.

| Портал | Уровень | Intel | Начальное время | Роль |
|---|---:|---:|---:|---|
| Mossbound Door | 1 | 70% | 54 мин | Быстрый старт, одна экспедиция |
| Mirror Rift | 2 | 45% | 18 мин | Неопределённые показания |
| Azure Bloom | 3 | 100% | 120 мин | Немедленная проверка Safe Close |
| Silent Arch | 4 | 100% | — | Уже закрытый архив |
| Void Passage | 5 | 30% | 18 мин | 7 существ, высокий риск |
| Crimson Gate | 6 | 10% | 10 мин | Критический риск и 3 существа |

**Observer** — атомарная экспедиция без ожидания нескольких минут. Intel растёт вместе с энергией; каждый повтор дороже и даёт меньше данных:

- Intel = min(остаток до 100, max(8, floor((32 − 2 × difficulty) / (1 + 0.3 × observerCount)))).
- Цена энергии = 4 + 2 × (difficulty − 1) + 2 × observerCount.
- CRITICAL, карантин, Intel 100% или недостаток свободной ёмкости энергии блокируют отправку.
- Данные экспедиций раскрывают особенности мира и повышают уверенность, но обязательная телеметрия всегда видима.
- Подтверждённая экспедиция и её возвращение записываются как пользовательское и системное события.

Детерминированная политика «исследовать по сложности, стабилизировать при запрете экспедиции, закрывать исследованные» проходит все шесть порталов: **37 операций**, зелёный требует **1 экспедицию**, красный **8 экспедиций**. Это проверка правил, не измерение длительности человеческой игры. Исходный резонанс — **38%**. Две минуты без действий не вызывают аварии.

## Риск и сеть

Внутренний risk engine сохранён. В каждой группе применяется один порог:

| Фактор | Баллы |
|---|---|
| Стабильность ≤20 / ≤40 / ≤60 | +35 / +25 / +10 |
| Энергия ≥90 / ≥75 / ≥60 | +25 / +15 / +5 |
| Осталось ≤5 / ≤15 / ≤30 минут | +25 / +15 / +5 |
| Существ ≥6 / 1–5 | +15 / +8 |
| Неопределённость | +10 |

Сумма ограничена 100. LOW 0–24; MEDIUM 25–49; HIGH 50–74; CRITICAL 75–100.

Вклад портала = вес **1 / 3 / 7 / 12** по его **внутреннему** уровню × (1 + 0.08 × (difficulty − 1)). Карантин умножает вклад на **0.15**; закрытый/схлопнувшийся портал даёт 0.

**Network Pressure** = min(25, round(0.5 × сумма вкладов остальных порталов)). Сам портал исключён. **Effective Risk** = min(100, Intrinsic Risk + Network Pressure). Эффективный риск не подаётся обратно во вклад — рекурсивного разгона нет.

**Lab Resonance** = min(100, round(1.2 × сумма вкладов)). Уровни: STABLE <25, ELEVATED <45, DANGEROUS <70, CRITICAL ≥70. В HUD показаны число и уровень; по клику — сводка с источниками. Эффективный риск используется в действиях, рекомендациях, реестре, приоритетах и VFX.

## Действия

- **Stabilize:** +30 стабильности, −15 энергии, +15 минут с ограничениями 0–100. При стабильности ≥90 и энергии <60 повтор запрещён. Высокую энергию разрешено снижать и при высокой стабильности, чтобы исследования не попадали в тупик.
- **Mark Uncertain:** добавляет uncertainty penalty к Risk и включает Caution Protocol. Пока неопределённость активна, Stability деградирует медленнее, а следующая успешная Observer expedition получает бонус Intel и меньшую стоимость Energy. Успешный Observer снимает uncertainty и расходует Caution Protocol.
- **Quarantine:** Intel не растёт, наблюдатель запрещён, таймер идёт с четвертью скорости, вклад в сеть — 15%. Это нерешённый портал.
- **Reactivate:** возвращает обычные таймер и вклад, стоит 6 + difficulty энергии. Переключения карантина разделены 10 секундами **активного игрового времени**. Меню не сокращает cooldown.
- **Safe Close:** Intel 100% **и** нет известных существ.
- **Force Close:** доступен и при неполном Intel или существах, но только с явным предупреждением. Это аварийное сдерживание, не исследование; в отчёте отдельный счётчик.
- Закрытые, схлопывающиеся и потерянные порталы не допускают обычных действий.

Все допустимые действия имеют предпросмотр из той же предметной функции, что и commit. Подтверждение повторно валидируется; защита от двойного нажатия сохранена. Журнал сохраняется до новой смены, чтобы итоговые числа не теряли основание.

## Время, схлопывание и завершение

Единые фазы: **RUNNING / PAUSED / GAME_OVER / SHIFT_COMPLETE**. Монотонный clock обновляет домен дважды в секунду, отдельно от Canvas и движения. Системные окна — Settings, How to Play, Registry, Event Log, System Report и AI Worklog — а также скрытая вкладка останавливают игровое время. Просмотр портала и выбор действий симуляцию не останавливают. Декоративный ambient может продолжаться. Возврат и перезагрузка создают свежую временную опору: накопленного времени паузы и offline-наказания нет.

Остаток отображается как m:ss. На 30 сек усиливаются эффекты, на 10 сек цифры становятся тревожными, на 3 сек появляется рамка предупреждения. При 0 портал переходит в **collapsing на 1.5 сек**, затем **collapsed**. Один переход создаёт один collapse и один resonance shock.

Удар детерминированно увеличивает энергию соседей, снижает стабильность и оставшееся время. Для intrinsically HIGH/CRITICAL он сокращает (30 + 4 × resonance) × difficulty / 3 секунд, для остальных — 10 секунд. Энергия растёт на round(6 + floor(resonance / 10) + difficulty), стабильность падает на round(4 + resonance / 12). Карантин умножает последствия на 0.25. Значения ограничиваются допустимыми диапазонами. Нулевое время запускает каскад. Порядок одновременных событий фиксирован по сложности и ID; большие и малые временные шаги дают одинаковый результат.

**Laboratory Lost:** схлопнулись минимум 3 портала (либо все в неполной тестовой сети). Одна потеря не уничтожает обычную лабораторию автоматически. Симуляция останавливается, доступны реальные итоги, журнал инцидентов и Restart.

**Shift Complete:** каждый оставшийся открытый портал имеет Intel 100%, LOW effective risk и снятую неопределённость; карантин/схлопывание не допускаются. Закрытые порталы и до двух локализованных потерь могут входить в итог сдерживания. Принудительное закрытие всей сети тоже завершает смену, но **не выдаёт 6/6 исследований**. Итог честно показывает реальный Intel, потери и принудительные закрытия. Пустой QA-сценарий не является победой.

**Restart Shift** — один pipeline из настроек и финальных экранов. Сбрасывает порталы, Intel, таймеры, cooldown, события, эффекты, выбор и позицию персонажа; сохраняет язык, звук и подтверждение обучения. Системный reduced motion остаётся в силе.

## Управление и доступность

WASD / стрелки — движение; клик по арке — удалённый осмотр; E рядом с порталом — взаимодействие. Реестр используется только для мониторинга. Escape сначала отменяет preview, затем закрывает окно. Tab остаётся в модальном окне. RU/EN переключает интерфейс. На узком экране доступны крупные карточки; виртуального джойстика нет.

Путь центр → дорожка → ступени → точка взаимодействия непрерывен. Боковые камни и декор непроходимы. Существующая система движения, глубины и collision map не переписана. `/?debug` показывает карту для визуальной отладки.

## Сохранение и ошибки

`rift-warden-state-v3` хранит порталы, журнал, фазу, активное время и финальный резонанс. Схема проверяет числа, Intel, сложность, cooldown, жизненный цикл, категории событий, даты и дубликаты ID. Невозможный финальный статус отвергается. v2 мигрируется с начальными значениями новых полей; исходный v2-ключ при миграции не перезаписывается. Старое прохождение не позволяет восстановить неизвестную историю исследований; начальные Intel берутся из seed.

Невалидное сохранение даёт понятное предупреждение и свежую смену; при запрете/quota localStorage работа в памяти продолжается. ErrorBoundary показывает понятный fallback при ошибке рендера. Пустая лаборатория сохраняет журнал; Restart очищает игровые сохранения всех поддерживаемых версий.

## Архитектура и ассеты

- `src/domain/risk` — прежняя внутренняя формула.
- `src/domain/simulation` — Intel/стоимость, нерекурсивная сеть, clock, lifecycle, cascade, end states.
- `src/domain/actions`, `validation`, `report` — общий preview/commit, ограничения, рекомендации и отчёт.
- `src/hooks/useSimulationClock.ts`, `src/App.tsx` — тонкая связь единого runtime с React и модальной паузой.
- `src/data/labLayout.ts`, `src/game` — неизменная геометрия, движение, collision/proximity.
- `src/components/game` — фон, персонаж, один Canvas эффектов; UI — в `components/ui` и `components/portal`.
- `src/storage` — миграция и валидация; `src/tests` — предметные и интеграционные проверки.

Принятый фон **не перегенерирован**: [asset-lock-v3.md](docs/asset-lock-v3.md). Фон и лаборант созданы ImageGen в предыдущих итерациях; происхождение — [assets.md](docs/assets.md). Локальные Press Start 2P / PT Mono с кириллицей и OFL-лицензиями. Активные поля/VFX/существа — отдельный слой; нарисованный свет на кирпичах остаётся частью арта даже после закрытия.

## Проверки и ограничения

**142 автотеста / 14 test files**: прежние правила ТЗ плюс стоимость/Intel, давление, карантин, время, pause/resume, cascade, end states, restart, storage v3 и audit rendering. [Фактическая браузерная QA](docs/qa-checklist.md) отделена от автоматических тестов.

Для ускоренной локальной проверки финальных экранов после build можно запустить `node tools/serve-qa.mjs` и открыть http://127.0.0.1:4185/cascade.html или /finish.html. Это отдельный тестовый сервер с явно подготовленным сохранением; он **не входит в production** и не является режимом проверяющего. Обычное приложение начинается с таблицы seed выше. Другой порт: переменная окружения `QA_PORT`.

Локальное демо без сервера, аккаунтов, экономики или настоящей телеметрии. Экспедиция мгновенная, миры раскрываются подготовленными данными. Баланс детерминированный; широкого пользовательского плейтеста и матрицы реальных мобильных устройств не было.

## AI Worklog

Подробный AI Worklog встроен непосредственно в приложение.

Откройте приложение и нажмите **AI WORKLOG** в левом нижнем углу.

В нём указаны:

- использованные AI-инструменты;
- время разработки;
- распределение работы между автором и AI;
- этапы и ключевые промпты;
- решения автора;
- ошибки AI и внесённые исправления;
- способы проверки;
- возможные улучшения продукта.

По уточнению автора: **примерно 15+ часов активной разработки**, без поминутного учёта; токены не подсчитывались. Роли, промпты, ошибки AI и ручные решения автора описаны без выдуманных метрик. За разработку использовано 9 пятичасовых лимитных окон Codex: 3 через ручной сброс лимита и 6 после ожидания следующего доступного окна. Это usage quota, а не token count. Суммарное количество токенов не подсчитывалось.
